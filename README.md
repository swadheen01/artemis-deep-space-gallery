# Artemis II: The Deep Space Gallery

A multi-page space flight visual journey built entirely with standard, semantic HTML5, zero JavaScript runtime dependencies, local media assets, and accessible navigational structure.

## Overview

Chronicles NASA's crewed circumlunar test flight (Artemis II) around the Moon through four interconnected modules:
* **Welcome Portal (`index.html`)**: Entry landing page introducing the lunar voyage.
* **Window Gallery (`gallery.html`)**: Curated exhibition of 14 downloadable high-resolution images across Earth, Moon, eclipse, and recovery phases.
* **Mission Trail (`mission.html`)**: Chronological flight trajectory log, route map, mission perspective table, and journey signals matrix.
* **Print Station (`print-request.html`)**: Interactive requisition station showcasing native HTML5 form controls and client-side validation.
