Artemis II: The Deep Space Gallery

Project documentation and code explanation

1. Project overview

This is a four-page Artemis II website. It presents a welcome page, a downloadable image gallery, a mission-trail page, and a print-request form. The site uses local images stored in the images folder and links all pages through a shared navigation menu.

FilePurpose
index.htmlWelcome page and visual entry point.
gallery.htmlDownloadable Earth, Moon, eclipse, and recovery image collection.
mission.htmlMission path, mission phases, reference facts, and journey signals.
print-request.htmlPrint-request form and gallery-card selection list.

2. index.html — Welcome page

The page starts with the HTML5 document declaration, language setting, character encoding, responsive viewport metadata, page description, and a page title. These details help browsers display the page correctly and help search engines understand its subject.

The body uses the local lunar-flyby image as a background. Its inline background properties prevent repetition, make the image span the page width, and position the scene lower on the page so the upper area remains dark and readable.

The header contains the gallery title and mission tagline. The nav contains links to all four pages. The main welcome section introduces Artemis II and has a form button that takes visitors to gallery.html.

An empty, labelled section intentionally leaves space for the lunar background to remain visible. The footer supplies the project copyright line. HTML comments in this file identify the header, navigation, welcome content, image-viewing space, and footer for easier study.

3. gallery.html — Downloadable image gallery

The gallery is organised into semantic sections: “Earth: The Long Look Back,” “Lunar Flyby,” “Eclipse Studies,” and “Return.” Each image is inside an article and figure, followed by a figcaption. This gives every photograph a meaningful title and explanation.

Every picture is wrapped in an anchor element with the download attribute. Clicking the picture or its “Download image” link downloads the local original image file rather than sending the visitor to an external website. Alt text describes each image for visitors using screen readers.

The gallery includes 14 cards: Crescent Earth; Earth Through Orion’s Window; Looking Back at Earth; Earth Perspective; Crew Window View; Backlit Earth; Artemis and Earth; The Far Side Atlas; New Moon View; Edge of Lunar Day; Setting Earth; View from Orion; In Eclipse; and Homeward Under Parachutes.

4. mission.html — Mission Trail

The Mission Trail uses an ordered list to describe four story phases: launch, outbound travel, lunar flyby, and the homeward journey. Each phase is placed inside an article, which makes its content independent and meaningful.

A figure displays artemis path.jpg. The image and its text link are downloadable, and the caption explains that it represents launch, lunar flyby, and trans-Earth return. A fact table provides quick mission context.

The “Signals from the Journey” table was moved here from the welcome page. Its three cells explain the roles of Earth as home, the Moon as the horizon, and Orion as the crew vessel.

5. print-request.html — Print Station

Print Station uses a deep-navy background to maintain the space theme. The page contains a form with a name field, an email field, gallery-card selection, print-size selection, terms checkbox, and submit button.

The email field and terms checkbox use required, so the browser checks them before allowing submission. The gallery-card dropdown contains every image title currently displayed in gallery.html. Because the form action is blank, it is a front-end demonstration and does not send an actual order to a server.

6. Navigation, images, and accessibility

  • Each page has the same navigation destinations: Welcome, Window Gallery, Mission Trail, and Print Station.
  • All local image paths begin with images/. Spaces in filenames are written as %20 in links where needed.
  • Every displayed image has descriptive alt text.
  • Section headings, captions, tables, labels, and landmark elements such as header, nav, main, and footer provide a clear semantic structure.
  • The website uses no JavaScript. The welcome page includes only small inline background-positioning rules because precise image placement cannot be controlled with legacy HTML background attributes alone.

7. How to run the project

  1. Keep all four HTML files and the images folder together inside artemis-deep-space-gallery.
  2. Open index.html in a modern browser.
  3. Use the navigation links to visit the remaining pages.
  4. Use the image links in the gallery to download local copies.
