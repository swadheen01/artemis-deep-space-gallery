01 Project Overview & System Architecture

Artemis II: The Deep Space Gallery is an educational web application designed to chronicle NASA's upcoming crewed circumlunar test flight. The application is crafted entirely in clean, semantic HTML5 without requiring external frameworks or JavaScript, highlighting the expressive power, resilience, and accessibility of fundamental web standards.

The web project consists of four interconnected core pages sharing a unified navigation schema, persistent deep-space color themes, and dedicated functional responsibilities:

Filename Module Name Key Features & Elements Primary Purpose
index.html Welcome Portal <header>, <nav>, lunar background, GET action form Visual landing page welcoming users and establishing the lunar voyage atmosphere.
gallery.html Window Gallery 14 <article> cards, <figure>, <figcaption>, download attributes High-resolution downloadable exhibition of Earth, Moon, eclipse, and recovery photography.
mission.html Mission Trail Ordered trajectory <ol>, route diagram, perspective table, signal matrix Curated scientific timeline tracking the four phases of Orion's translunar journey.
print-request.html Print Station Semantic <form>, <fieldset>, <select>, HTML5 validation Interactive requisition station allowing visitors to order fine-art prints of any exhibition.

02 index.html — The Welcome Portal

The main file, index.html, serves as the ceremonial entrance into the experience. It establishes the celestial context by presenting a majestic lunar wallpaper featuring the Earth setting behind the Moon's cratered horizon.

Key Structural Components in index.html Portal Module
  • Document Type & Meta: Declares <!DOCTYPE html> with UTF-8 encoding and responsive viewport configuration.
  • Background Composition: Combines legacy HTML attributes (background, bgcolor, text, link) with non-invasive inline styles (background-repeat: no-repeat; background-position: center 200px;). This prevents repetition while keeping the top reading corridor dark and pristine.
  • Direct Navigation Gateway: Implements a pure HTML <form action="gallery.html" method="get"> that encases a prominent button <button type="submit">✦ Enter the Window Gallery ✦</button>, offering seamless routing without JavaScript handlers.
  • Lunar Viewing Buffer: An intentional spacer element <section style="height: 230px;"> ensures the high-resolution setting Earth image remains visible and unobstructed by text.

03 gallery.html — The Window Gallery

gallery.html serves as the central visual exhibition. Styled with an indigo-violet backdrop (bgcolor="#160B35"), it organizes 14 curated high-resolution photographs into thematic curatorial sections.

Curatorial Sections & Exhibition Breakdown Visual Exhibition
  • Earth: The Long Look Back (7 Cards): Features Crescent Earth, Earth Through Orion's Window, Looking Back at Earth, Earth Perspective, Crew Window View, Backlit Earth, and Artemis & Earth.
  • Lunar Flyby (4 Cards): The Far Side Atlas, New Moon View, Edge of Lunar Day, and Setting Earth.
  • Eclipse Studies (2 Cards): View from Orion and In Eclipse showing the corona-haloed Moon.
  • Return (1 Card): Homeward Under Parachutes capturing ocean splashdown descent.

Semantic Architecture & Native File Downloads

Instead of generic image links, each card utilizes the semantic pairing of <article>, <figure>, and <figcaption>. Furthermore, all images are enveloped within anchor tags carrying HTML5 download attributes. 

<article>
  <figure align="center">
    <!-- Download attribute triggers immediate browser download of local high-res asset -->
    <a href="images/crisent%20earth.jpg" download="crescent-earth.jpg">
      <img src="images/crisent%20earth.jpg" alt="Crescent Earth emerging from black space" width="600">
    </a>
    <figcaption>
      <strong>Crescent Earth.</strong> A slim, luminous curve of home.
      <a href="images/crisent%20earth.jpg" download="crescent-earth.jpg">Download image</a>
    </figcaption>
  </figure>
</article>
Accessibility & Best Practice Highlight
  • Informative alt Attributes: Every photograph provides screen-reader descriptions conveying celestial context rather than decorative placeholders.
  • URL Encoding: Filenames containing whitespace use proper percent-encoding (e.g., crisent%20earth.jpg) ensuring bulletproof URI resolution across all operating systems.

05 print-request.html — The Print Station

print-request.html functions as an interactive acquisition station. Styled with a deep navy tone (bgcolor="#071A33") with rose accents (#FB7185), it demonstrates comprehensive HTML5 form controls and native client-side validation.

Form Controls & Input Specifications Interactive Form
  • Grouping Landmark (<fieldset> & <legend>): Groups the order fields into a logical module titled "Requester details", providing critical context for assistive technologies.
  • Name Input: Text field utilizing autocomplete="name" to leverage user-agent autofill.
  • Email Input with Built-in Validation: Utilizes type="email" and required, forcing the browser to reject submission unless a valid RFC-compliant email address format is provided.
  • Exhibition Selector: Dropdown <select id="photo"> containing all 14 artworks from gallery.html for guaranteed cross-module consistency.
  • Print Dimensions: Select input providing curated print sizes: A4 Desk Mission, A3 Observatory Wall, and A2 Deep Space Statement.
  • Compliance Agreement: Checkbox with required validating consent prior to form transmission.

06 Engineering Principles & Best Practices

Key Architectural Strengths of the Project
  1. Strict Semantic Web Standards: Meaningful landmarks (<header>, <nav>, <main>, <section>, <article>, <figure>, <aside>, <footer>) replace generic <div> soup.
  2. Accessibility (A11y): ARIA labels (aria-label, aria-labelledby), explicitly linked form labels (<label for="...">), and descriptive alt text support assistive screen readers out of the box.
  3. Native Offline Capabilities: All 14 visual assets and mission diagrams reside inside the local images/ folder. The site works flawlessly without internet access or CDN availability.
  4. Progressive Enhancement: Relies on native browser capabilities (such as form validation and download triggers) ensuring 100% functionality on modern browsers, legacy platforms, and text-based browsers alike.

07 Execution & Deployment Guide

  1. Directory Verification: Ensure the project folder contains index.html, gallery.html, mission.html, print-request.html, and the images/ subfolder.
  2. Direct Launch: Double-click index.html to open the welcome portal in any modern web browser (Edge, Chrome, Firefox, Safari).
  3. Navigation: Use the top navigation bar or the portal button to tour the collection, inspect trajectory data, or test print requests.
  4. Downloading Assets: Click on any picture in the Window Gallery to initiate an instant offline download of the local high-resolution artwork.
